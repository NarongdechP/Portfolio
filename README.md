## 📌 Projects

### 1. DTI262 – Data Mining and Its Applications (Apr – May 2025)
Predicting maternal health risks using data mining techniques.

- **Project File:** [`Project_DTI262.py`](./Project_DTI262.py)
- **Overview:**
  - Built and evaluated Random Forest models on maternal health dataset from UCI.
  - Performed data preprocessing, feature encoding, cross-validation, and parameter tuning (`n_estimators`, `max_features`).
  - Evaluated models using accuracy, F1-score, precision, and recall.
- **My Contributions:**
  - Designed and implemented the entire Python code for preprocessing, modeling, and evaluation.
  - Developed experiments to improve prediction accuracy.
  - Authored and edited parts of a team article in Thai on Medium, ensuring correct technical terms.
